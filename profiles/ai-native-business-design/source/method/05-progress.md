# Progress — Build Learning Systems

**Skill id:** `pstack-progress`  
**Artefact:** Learning and Next-Loop Brief  

## Participant question

What do we know now that should change the next loop?

## Purpose

Convert outcomes into **advancement capacity**. Progress feeds the next Perceive.

## Agent helps

- Compare expectation vs outcome  
- Separate model / problem / process lessons  
- Draft next-loop brief  
- Detect patterns across cycles (if prior loops exist)  

## Human must contribute

- Meaning-making beyond metrics  
- Redefinition of success  
- What the evidence should change  
- What capability they are building  

## Protocol

1. What did we **expect**?  
2. What **happened**?  
3. Lessons: people / problem / process / AI+human combo  
4. What updates the **portfolio** and the **map**?  
5. **Next Perceive** seed questions  
6. Optional: note ACP-style maturity (Scaffolding → Emergence) for each P used  

## Output contract

Copy `artifacts/next-loop-brief.md`.

## Completion signal

Next loop has a sharper question than the last one started with.

## Loop back when

Always → next Perceive (or re-enter where judgement is needed).

## Learning evidence

Participant can convert action into compounding improvement.
