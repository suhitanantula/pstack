# PStack Method Pack — start in 5 minutes

**Version:** 2.0.0-course-draft  
**No terminal required.**

## What you need

- A **live strategic challenge** you have authority (or access) to work on  
- Claude Desktop, ChatGPT, or any AI that can follow file instructions  
- A place to save markdown artefacts (Project folder, Google Drive, Box, Notes)

## Install options

| Path | Use when |

| [Claude Desktop Skills](../../packs/dist/INSTALL-CLAUDE-DESKTOP.md) | You use Claude and can upload skills |

| **This folder as Project files** | Skills blocked, free tier, or fastest start |

### Project-files path (always works)

1. Create a new **Project** (Claude) or **Custom GPT / Project** (ChatGPT).  
2. Attach all files in this `source/method/` folder (or paste `00-loop.md` into instructions).  
3. Say: *“Read the PStack loop. I have a live challenge: [one sentence]. Start with Perceive.”*

## The loop (default order)

```
Perceive → Perform → Portfolio → Pause/Promote → Progress
         ↖________ loop / return when reality teaches ________↗
```

You can enter at any P. Returning is normal.

## First session script

1. Fill `artifacts/strategic-learning-brief.md` (intake).  
2. Run **Perceive** → save `situation-map.md`.  
3. Run **Perform** → smallest intentional move + evidence.  
4. Run **Portfolio** → at least 2–3 live options.  
5. Run **Pause/Promote** → recommendation + kill list + keep-alive.  
6. Run **Progress** → what changed for the next loop.  
7. Optional: fill `../../learn/practice-pulse.md` if sharing with the course.

## Co-intelligence rule

At every step ask: **Whose judgement improves this P right now?**

- You bring: context, stakes, values, taste, accountability  
- AI brings: pattern scan, variation, synthesis, structure  
- Together: better than either alone — you still own the bet
