# Starter: New Venture / Design Challenge

**When:** Fuzzy brief; don’t know the real problem yet.  
**Sequence:** Perceive → Perform → Portfolio → Pause → Progress  

1. Perceive — people + problem behind the problem → Situation Map  
2. Perform — smallest prototype / test with a real person → Live Move  
3. Portfolio — 3 directions with different assumptions  
4. Pause — promote / kill / keep-alive  
5. Progress — next-loop brief  

**Time:** multi-week module or 2-day intensive
