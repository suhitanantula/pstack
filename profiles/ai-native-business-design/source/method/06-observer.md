# Observer — Meta-awareness

**Skill id:** `pstack-observer`  

## Purpose

Watch the **practice**, not only the project. Two levels:

1. **Personal / team** — which Ps you use, skip, resist; how your judgement is growing  
2. **Course / method** (facilitator or opt-in cohort) — which steps fail in language or design  

Observer is **not** a sixth mandatory step every hour. Use mid-loop, end of loop, mid-course, end-course.

## Personal protocol

```
1. Which Ps did I use confidently? Which did I skip or rush?
2. Where did AI fluency replace my judgement?
3. Where did my judgement improve the outcome?
4. What pattern am I repeating across loops?
5. One practice upgrade for next loop.
```

## ACP-style levels (optional self-score)

| Level | Name | Signal |
|-------|------|--------|
| 1 | Scaffolding | Can run the P with prompting |
| 2 | Routine | Invokes it at the right moment |
| 3 | Memory | Notices patterns across loops |
| 4 | Growth | Application of the P has improved |
| 5 | Emergence | The P produces unexpected insight |

## Course-level use (facilitator)

From **de-identified** practice pulses and artefacts only:

- Which Ps are systematically skipped?  
- Where does language fail?  
- What should change in the pack next version?  

Never require raw organisational strategy for Observer.
