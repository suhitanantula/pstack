# Portfolio — Designing for Anti-Fragility

**Skill id:** `pstack-portfolio`  
**Artefact:** Live Portfolio of Plays  

## Participant question

What options become visible now that we have acted and learned?

## Purpose

Hold a **live field of options** — safe, bold, hybrid — as working plays, not slideware. Prototype before you present.

## Agent helps

- Generate contrasting options  
- Make options tangible (sketches, scenarios, prototypes)  
- Surface assumptions and failure modes  
- Preserve worthwhile optionality  

## Human must contribute

- Taste and strategic preference  
- Risk appetite  
- Contextual fit  
- Which options deserve attention  

## Protocol

1. List **at least 3** distinct directions (or 2 if genuinely constrained — state why).  
2. For each: assumption, evidence so far, failure mode, reversibility.  
3. Mark which is under **active test** (from Perform).  
4. Mark which are **keep-alive** vs **parked**.  
5. Explicitly note what you are **not** expanding into (light prune).  

## Output contract

Copy `artifacts/portfolio-of-plays.md`.

## Completion signal

Options are contrasted (not three renames of one idea) and at least one is grounded in Perform evidence.

## Loop back when

All options rest on the same untested assumption → Perform. Framing wrong → Perceive.

## Learning evidence

Participant can maintain disciplined optionality without avoiding a recommendation.
