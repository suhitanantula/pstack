# Assessment rubric — practice, not AI fluency

Score each 1–4. Do **not** reward verbosity or polish alone.

| Dimension | 1 Weak | 4 Strong |
|-----------|--------|----------|
| **Framing** | Restates brief only | Problem behind problem + people |
| **Evidence use** | Claims without type | Separates E / I / U |
| **Option quality** | One idea rebranded | Real contrast + assumptions |
| **Judgement transparency** | Vague next steps | Promote + kill + bet + review |
| **Learning** | No update | Next loop sharper than start |
| **Reuse readiness** | Needs facilitator | Can name which P to run next |

## Pass for pilot

- All five step artefacts present (can be short)  
- Kill list non-empty on Judgement Record  
- Practice pulse submitted
