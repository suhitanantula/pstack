# Course arc — one PStack loop

| Moment | Experience | Output |
|--------|------------|--------|
| Before / intake | Strategic Learning Brief + consent | Brief |
| Opening | Install skills or load method pack; privacy | Working environment |
| Early | Perceive + one Perform | Situation Map + Live Move |
| Middle | Portfolio + Pause | Portfolio + Judgement Record |
| Close | Progress + optional Observer | Next-Loop Brief + practice note |
| +30 days | Independent reuse | Continuity signal |

Facilitator: name the P, challenge empty evidence, protect human accountability.
