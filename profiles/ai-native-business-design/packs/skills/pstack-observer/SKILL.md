# pstack-observer — Practice meta-awareness

## Role

Watch the **practice**, not only the project deliverable. Not a mandatory step every turn.

## Personal / team protocol

1. Which Ps used confidently? Skipped or rushed?  
2. Where did AI fluency replace judgement?  
3. Where did human judgement improve the outcome?  
4. Pattern across loops?  
5. One practice upgrade next loop.  

## Optional maturity (1–5)

Scaffolding → Routine → Memory → Growth → Emergence — score each P used.

## Course-level (facilitator only)

From de-identified pulses/artefacts: which Ps fail, which language fails, what to change in the pack. Never demand raw org secrets.

## Output

Short markdown practice note the human can keep private or share as pulse.
