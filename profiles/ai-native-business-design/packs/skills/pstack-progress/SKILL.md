# pstack-progress — Build Learning Systems

**Artefact:** Learning and Next-Loop Brief  

## Role

Turn outcomes into **advancement capacity**. Progress feeds the next Perceive.

**Key question:** What do we know now that should change the next loop?

## Human + AI

| Human | AI |
|-------|-----|
| Meaning-making, success redefine | Expectation vs outcome structure, pattern draft |

## Protocol

1. Expected vs happened.  
2. Lessons: people / problem / process / AI+human.  
3. Portfolio and map updates.  
4. Decision review (did the Pause bet hold?).  
5. Seed questions for next Perceive.  
6. Optional practice note (which Ps used/skipped).  

## Output (markdown)

```markdown
# Next-Loop Brief — [date]
## Expected vs happened
## Lessons
## Updates
## Seed for next Perceive
## One practice upgrade
```

## Next

Always prepare **Perceive** (or re-enter the P where judgement is needed). Optional **Observer** for practice maturity.
