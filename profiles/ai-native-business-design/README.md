## Promise

> Enter with a live challenge. Learn a five-step strategic rhythm with AI. Leave with a defensible intervention, a visible judgement trail, and a PStack you can keep using.

## What this is

A **markdown-first method pack** for teaching and giving the 5Ps of Loop Design:

| Layer | Path | Role |
|-------|------|------|
| Method source | `source/method/` | Canonical authoring (edit here) |
| Installable skills | `packs/skills/` | Claude Desktop / ChatGPT / Agent Skills zips |
| Dist + how-tos | `packs/dist/` | Participant install guides + zip |
| Course | `course/` | Facilitation, assessment, privacy |
| Learn | `learn/` | Practice pulse + 30-day follow-up |
| Workspace | `workspace/` | Empty artefact templates for participants |

## The five steps

1. **Perceive** — Never Forget the People  
2. **Perform** — Move with Intention  
3. **Portfolio** — Designing for Anti-Fragility  
4. **Pause/Promote** (`pstack-decide`) — Choose What Matters  
5. **Progress** — Build Learning Systems  

Plus **Observer** (personal + course-level reflection) and umbrella **pstack** (router).

Loop, not ladder. Co-intelligence: *Whose judgement improves this P right now?*

## How participants get it

1. **Claude Desktop** — upload skill zips → enable Skills ([INSTALL-CLAUDE-DESKTOP.md](packs/dist/INSTALL-CLAUDE-DESKTOP.md))  
2. **ChatGPT** — Skills UI or Custom GPT fallback ([INSTALL-CHATGPT.md](packs/dist/INSTALL-CHATGPT.md))  
3. **Always works** — attach `source/method/` files to a Project  

No terminal required for the course path.
