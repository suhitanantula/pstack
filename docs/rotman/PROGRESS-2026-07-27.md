# Progress Report — Rotman Course Edition Seed — 2026-07-27

## What We Were Testing

Could the existing PStack become the participant runtime for AI Native Business Design without creating a competing method implementation?

## What Happened

- The canonical PStack repository was mapped across skills, distribution, memory, artefacts and the Cloudflare runtime.
- A local isolated fork was created on `rotman-course-edition`.
- The participant-facing order was confirmed as Perceive → Perform → Portfolio → Pause → Progress.
- The fork gained a current-system map, participant rhythm and packaging architecture.
- A distribution drift was found: canonical Perceive contained a prior-knowledge step missing from the Codex plugin copy.
- The plugin copy was regenerated and the drift check passed.
- No canonical PStack files or untracked Cloudflare dogfood scripts were changed.
- No public Rotman-branded repository was created.

## Model Lesson

The agents are already capable of running the five distinct cognitive practices. The main model-design challenge is maintaining shared case state and visible transitions without allowing a single conversational agent to blur the Ps together.

## Problem Lesson

The problem is not “build five agents for a course.” The problem is “package an existing co-intelligence method so non-technical participants can learn it, use it on sensitive live work and continue independently.”

## Process Lesson

Inspecting the actual repository before designing the course prevented a duplicate architecture. Running the distribution check also showed that packaging reliability must be treated as part of the learning product, not as maintenance hidden beneath it.

## Pause Decision

**Promote:** a dual-path PStack course profile—managed browser by default, native installation as the deeper continuation.

**Keep alive:** native-first delivery for small technically confident cohorts.

**Kill for now:**

- a new standalone five-agent framework;
- a public Rotman-branded GitHub fork before institutional approval;
- a browser chatbot that hides the five practices;
- automated assessment or admission decisions.

## For Next Sprint

- Start with: define the Strategic Learning Brief and participant workspace contract.
- Do differently: generate all runtime distributions from one canonical method source.
- Kill immediately: any design that treats agent prose as evidence of participant capability.
- Investigate: Rotman IT, privacy, accessibility, supported AI environments and credential pathways.
